# Hayder

**Hayder** is a personal AI operations assistant designed to remember ongoing work,
resume projects, organise business activity, and prepare actions for explicit approval.

## Core principle

> Hayder remembers. Hayder prepares. You approve important actions.

## Milestone 1

- Save project checkpoints
- Retrieve the latest checkpoint
- Return the exact next action
- Preserve checkpoint history

## Initial command

`Hayder, continue Xorwia.`
